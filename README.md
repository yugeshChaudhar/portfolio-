# 🚀 Yugesh Chaudhary – Personal Portfolio Web App

A clean, responsive, minimalist personal portfolio web application built for **Yugesh Chaudhary**. The project showcases web development skills, personal projects, contact information, and features an interactive embedded **Task Manager** widget powered by `localStorage`.

---

## ✨ Features

* **Minimalist & Responsive UI**: Clean CSS design using custom CSS variables, modern card layouts, flexbox, and grid.


* **Interactive Task Manager Widget**:
* Add, toggle completion status, and delete tasks.


* Filter tasks by `All`, `Active`, and `Done` status.


* Persistent task storage using browser `localStorage` (`bca_portfolio_tasks`).




* **Clipboard Email Copy**: Interactive utility allowing visitors to instantly copy the contact email address with dynamic toast feedback.


* **Smooth Navigation**: One-click smooth scrolling to sections (`About`, `Projects`, `Contact`) and a floating "Scroll to Top" button.


* **Project Showcase**: Displays key GitHub projects including *Task Manager* and *Sanduk Coop Management System* with direct source code links.



---

## 🛠️ Built With

* **HTML5**: Semantic document structure.


* **CSS3**: Custom design tokens, responsive breakpoints, smooth scrolling, and CSS grid/flexbox.


* **JavaScript (ES6+)**: Vanilla DOM manipulation, event delegation, and Web Storage API (`localStorage`).
